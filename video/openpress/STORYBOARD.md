# OpenPress — From a thought to a live site

20 seconds · 1920 × 1080 · 60 fps · silent · continuous camera choreography

Visual direction: white and soft stone, ink typography, OpenPress green. The
existing Elsewhere example supplies the photography, editorial typography, and
warm palette. A fictional, unbranded AI conversation demonstrates supported
OpenPress actions. No third-party client UI or endorsement is implied.

| Time | Attention and motion |
| --- | --- |
| 0–4s | “Your next website starts with a sentence.” A generous chat composer types “Create a travel journal called Elsewhere.” OpenPress is already connected. |
| 4–8s | The message sends. Chat glides left as a browser enters from the right. Masthead, photograph, and story progressively assemble. |
| 8–12s | “Make it warmer. Then publish it.” types into the chat. The website shifts from neutral white to the existing cream / terracotta theme. |
| 12–16s | A restrained green publish confirmation appears. The browser moves to center and grows; its address shows elsewhere.openpress.blog. This is an illustrative address, not a claim that this demo is deployed. |
| 16–18.5s | Hold the completed editorial site. Closing message: “From a thought. To a live site.” |
| 18.5–20s | Website recedes and the opening composition returns for a seamless loop. |

Three initial review frames: 3.2s (prompt), 10.8s (refine), 17s (published).
Final review includes intermediate transition frames and the last/first boundary.

Deliverables: MP4 master, smaller web MP4, poster, editable source, local review page.
The existing landing page stays unchanged during review.
