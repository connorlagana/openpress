# Three alternative directions

The original remains intact. All three alternatives are 18-second, silent,
1920×1080 / 60 fps films. Large text and fewer simultaneous messages improve
readability when embedded in a landing-page hero.

## 01 — Say it. Ship it.

A dark kinetic-typography launch film. Ink, electric lime, oversized headlines,
fast masked reveals, a compressed chat prompt, and a large website emerging
from the sentence. Designed to grab attention quickly.

0–3s: SAY IT / prompt. 3–6s: BUILD IT / browser takes shape. 6–10s: MAKE IT YOURS /
color request and visual transformation. 10–14s: SHIP IT / published address.
14–18s: branded payoff, then controlled reset.

## 02 — Somewhere worth sharing

An editorial travel film. The photograph fills the screen before pulling back
into the Elsewhere journal. Warm paper, serif type, restrained camera movement,
and a floating AI prompt give the result visual priority.

0–4s: immersive photograph and story title. 4–8s: photo becomes a website as the
AI request appears. 8–12s: refine to warm paper. 12–16s: publish and generous
hold on the journal. 16–18s: return into the photograph for the loop.

## 03 — Make it mine

A playful, graphic conversation for a designer portfolio. Lilac canvas,
large message bubbles, a floating portfolio card, and bold orange restyling.
Each user message causes a visible, immediate response.

0–4s: “Build my design portfolio.” 4–8s: portfolio slides into view. 8–12s:
“Bolder. Orange. More me.” changes its theme. 12–16s: “Publish it.” resolves
into a green live badge. 16–18s: final brand message and reset.

All UI is illustrative; AI is already connected and publishing is authorized.
Example URLs and portfolio content are fictional. No live sites are created.

## Motion and hook revision

Following review, all three now have stronger openings and more expressive motion:

- **Kinetic:** “One prompt. Real website.” Masked word entrances, a full-frame lime
  wipe, a perspective browser entrance, and a spring-driven LIVE stamp with confetti.
- **Editorial:** “One sentence. A whole website.” Cinematic image-to-layout morph,
  five staggered shutter panels, a warm light sweep, and a stamped publishing moment.
- **Conversation:** “Your website. Taking feedback.” Springing message bubbles,
  a radial orange burst during restyling, tilted portfolio motion, and a LIVE stamp.

All animation derives from the frame number. The comparison player is at
`studio/out/alternatives/index.html`; its reusable source is
`studio/review/alternatives.html`.
